# CYCLE — Mentoria individual

Página independente em um único index.html, com foto, fontes, estilos e microinterações incorporados. Não exige instalação ou compilação.

Todos os quatro CTAs de aplicação levam a https://cycle.mauriciocastello.com.br. Os links do menu continuam navegando pelas seções da página.

## Publicação

1. Extraia o ZIP e envie seu conteúdo para um NOVO repositório do GitHub, com index.html na raiz. Use um repositório separado do formulário de aplicação.
2. No Cloudflare Pages, crie outro projeto conectado ao novo repositório. Estrutura: Nenhum. Comando de build: vazio. Diretório de saída: ponto (.).
3. No novo projeto, abra Domínios personalizados e adicione mentoriacycle.mauriciocastello.com.br. Confirme o registro sugerido e aguarde a ativação. O arquivo CNAME sozinho não configura o domínio no Cloudflare Pages.

O formulário e o painel existentes continuam em seus próprios endereços. Este pacote contém somente a landing page, sem dados de candidatos ou credenciais.
